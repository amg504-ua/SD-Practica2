# Configuración

| Módulo | Configuración de Arranque |
|---|---|
| WM_Central | Puerto servidor sockets ofrecido al Monitor + IP / Puerto Kafka + Database Path|
| WM_FO | ID Operador + IP / Puerto Kafka |
| WM_WS_M | ID Estación + Puerto servidor sockets para Engine + IP / Puerto Central |
| WM_WS_E | IP / Puerto Monitor + IP / Puerto Kafka |
---

Database Path: La aplicación necesita saber dónde está el archivo SQLite.
